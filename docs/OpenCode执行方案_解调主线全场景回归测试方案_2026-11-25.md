# OpenCode 执行方案：解调主线全场景离线回归测试（2026-11-25）

## 0. 任务背景与目标

本轮在 `main`（`2b76be9`）之上完成了 3 项面向解调主线与锁定状态机的根治修改（当前在工作区未提交，涉及 11 个文件）：

1. **SFD 物理一致性门控**（`lib/phy/hrp/uwb_demod_sfd.cc`）：新增 `sync_before_sfd_ok()`，要求 SFD 候选前 4–8 个 SYNC 符号具备相干能量与相位对齐，阻断 payload 假峰伪装 SFD。
2. **锁定状态机 `Verify` 脱困**（`lib/runtime/uwb_target_lock_core.cc`）：`Verify` 状态遇到连续残差异常（`>= cfg_.residual_outlier_count`）时自动 `enter_reacquire()`，根治坏种子锁死。
3. **CFO 主线统一**（`lib/phy/hrp/uwb_demod_pipeline.cc` 等）：移除 Stage-2 `fit_cfo()` 交叉检查（仅保留 `!cfo_ok` 时的 fallback）并退役影子稠密 CFO 网格 `timing_fold_cfo_samples/corr`。

**本次回归目标**：
- 在全场景离线实采数据（干净/弱信号/宽松锁定/强干扰/SIC/近场/动态信道）及重型低 SNR 网格 QA 上，对比 **基线 A（`main` @ `2b76be9`）** 与 **候选 B（当前工作区修改）**，确认：
  1. 无任何场景的完整帧 FCS 退化、锁死或性能回退；
  2. `try2_loose`（宽松锁定）在去除 CFO 交叉检查后依然稳定自愈并锁后高通过率；
  3. 识别并记录当前主线在极端场景（弱信号/强干扰/动态信道/大频偏）下的剩余失败归因，为下一阶段优化提供数据支撑；
  4. 形成正式验收报告并同步更新 `开发状态.md`（不自动 `git push`）。

> **强制约束（遵守 `AGENTS.md`）**
> - 全部构建与测试命令必须带 `env -u LD_LIBRARY_PATH`；禁止 `-march=native`。
> - 性能/回放测试必须**严格串行、同环境对照**；有调度反馈的锁定回放必须采用 **ABBA 配对**（`A B B A`）。
> - **区分证据口径**：完整帧成功仅指 `PACKET status=OK && fcs=1`，不得将 SFD-only / PHR-only / `acq_seeds` 写成帧成功率；全部结果为**离线文件回放，未上板**，未做 MATLAB 逐样点交叉验证。
> - 出现 `raw_drop_samples > 0`（系统反压导致的读源丢样）的轮次必须标记作废并补跑，不得混入统计。
