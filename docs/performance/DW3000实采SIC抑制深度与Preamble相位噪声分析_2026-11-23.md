## 2. SIC 抑制深度评估结果

### 2.1 评估指标说明
- **`suppression_db`**（总能量消除）：$10\log_{10}(E_y / E_{\text{out}})$，包含热噪声底，理论上界受 `ideal_noise_ceiling_db` 约束。
- **`signal_only_supp_db`**（扣噪纯信号消除）：$10\log_{10}\!\big((E_y - E_n)/(E_{\text{out}} - E_n)\big)$，其中 $E_n$ 由包间静默段实测噪声功率估算；当残留已接近或略低于 $E_n$ 估算波动时记为 `99.00`。
- **`CIR_peak_supp_db` / `CIR_win[-16,48)_supp_db`**：对 Preamble 第 `16..239` 共 224 个 SYNC 符号按 `cfo_hz` 解旋并相干叠加，计算 1016-lag 圆周互相关功率谱在消除前后的比值（分别对应主径峰值与主径附近 `[-16, 48)` 样点多径窗），可提供超过 50 dB 的动态范围。
- **`post_sic_fcs_ok`**：单发数据集无第二路目标包，该项反映消除后残留自干扰是否仍能被自身再次解码成功（越低说明消除越彻底）。

### 2.4 SIC 关键结论
1. **CFO 尾段 refit 退化问题**：默认 `legacy`（`cfo_refit=0`）在 SFD 锚定后用最后 40 个 SYNC 符号（`~40.7 µs`）重拟合 CFO，并无条件覆盖 232-SYNC 的 `cfo_init_hz`：
   - 近距组 `cfo_init_hz` 包间相邻噪声为 `41.17 Hz`（`0.0063 ppm`），而 `cfo_refit_hz` 达 `237.97 Hz`（`0.037 ppm`），两者偏差极值达 `-716 ~ +818 Hz`；
   - 远距组 `cfo_init_hz` 标准差 `84.75 Hz`（`0.013 ppm`），`cfo_refit_hz` 达 `283.88 Hz`（`0.044 ppm`）。
   - 切换为 `skip2` 后，近距/远距的 `CIR_peak_supp_db` 分别从 `22.98 / 21.53 dB` 提升至 **`34.97 / 31.43 dB`**，自解码残留从 `36/100`、`30/100` 降至 `0/100`、`2/100`。
2. **多径窗长度限制**：`taps=20`（`lag_lo=-4`，仅覆盖约 `20 ns`）导致近距组 `CIR_win[-16,48)_supp_db` 卡在 `19.63 dB`；扩展至 `taps=48 (lag_lo=-12)` 后跳升至 **`27.94 dB`**（+8.31 dB，远距组 +5.00 dB 至 **`25.85 dB`**）。
3. **经验相位跟踪增益**：Preamble 段开启逐符号相位跟踪（`E_empirical`）后，近距/远距 `CIR_win[-16,48)_supp_db` 进一步达到 **`35.06 / 30.44 dB`**。

### 3.3 物理合理性与工程意义
1. **合理性评估**：在 $f_c = 6.4896\text{ GHz}$ 下，`2.65°`（`0.04623 rad`）对应等效时间抖动仅 **约 `1.13 ps` RMS**，且具备典型的集成 CMOS PLL 环路特征（`-77 dBc/Hz` 环内平台 + `~30–50 kHz` 环路带宽滚降 + `-93 ~ -94 dBc/Hz` 宽带基底），完全符合商用低功耗 DW3000 UWB SoC 的正常硬件表现。
2. **对 CFO 估计算法的影响**：`~40 µs` 短基线内的 `-77 dBc/Hz` 环内慢相噪会产生数度的相位漂移，直接导致 40-SYNC tail refit 产生 `~200+ Hz` 的斜率误差，从而验证了使用长基线 `cfo_init_hz`（或禁用短窗 refit）的必要性。
3. **对 SIC 抵消上限的约束**：在不使用逐符号/短时相位跟踪时，该 `2.65°` 相噪将静态信道单符号相干抵消的物理上限锁在 **~26.7 dB**；Preamble 段可通过经验相位跟踪突破至 **35 dB**（CIR 多径窗口径），而 Payload 段若需突破此上限，则需引入判决引导相位跟踪（DD-PLL）等机制。
