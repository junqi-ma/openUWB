## 3. 五项优化实现

### 3.1 S1：相干加权软极性（修复 `SFD_FAILED` 误杀）

- 合并原 `polarity_ok()` / `polarity_ok_cached()` 两份几乎相同的硬判决为
  `check_sfd_polarity_soft(sym_corr, seq, n_check)`：
  - `ref = Σ s_i·c_i`，`|ref|² ≤ 1e-24` 拒绝；
  - 每个非零符号投影 `p_i = (c_i·ref)·s_i`，统计 `pos_cnt / signed_sum / abs_sum`；
  - `N_nz ≤ 4`（IEEE legacy）：仍要求 `pos_cnt == N_nz`；
  - `N_nz ≥ 5`（`4z2` 8 个非零符号、`4z3/4z4` 更多）：允许 1 个弱反相
    （`pos_cnt ≥ N_nz-1`），且 `signed_sum ≥ 0.65·abs_sum`（反相能量 ≤17.5%）。
- 单符号瞬时翻号不再一票否决；移位旁瓣 / SYNC-only 窗口因 `pos_cnt` 与加权比双重门限仍被拒绝。

### 3.2 S2：低门限统一（消除 35% 弱包白扫 8 窗 + 离散网格）

- `scan_sfd_window()` 非 `par_only` 低门限分支的入口从 `0.02f` 下调为
  `kSfdGridPeakFloor`（`0.008f`），仍要求：
  - 背景 PAR ≥ 25（排除 SYNC-only 均匀窗）；
  - `window_best < 0.08` 时必须通过 `check_sfd_polarity_soft`。
- `>= 0.08` 直接通过、`>= sfd_detection_threshold` 直接通过的分支保持不变。
- 效果：`0.008 ≤ sfdmetric < 0.02` 的真包在**中心窗第 1 次**命中，`search_windows = 1`，
  不再进入 `±1..±4` 符号窗口与 `(-36,+36)` 离散网格。

### 3.3 S3：离散网格零堆分配 + 去标量滑窗能量 + 共享模板缓存

1. **扁平网格缓冲**：`run_discrete_grid` 原 `8 × 3` 个局部 `std::vector`（24 个）改为
   `scratch.sfd_grid_sym_{corr,pwr,valid}`，每个 delta 槽 `d ∈ [0,7]` 使用
   `stride = n_sym_slots` 切片；`sym_built[8]` 取代 `vector::empty()` 哨兵。
   预热后 `resize(8·n_sym_slots)` 不再分配（`reserve(8*544)` 覆盖 `≤511` 网格点 + `≤16` SFD 符号）。
2. **滑窗能量**：`scan_sfd_window` 初始功率改用 `window_power_8acc`；每个 lag 的
   离开/进入边界功率由一次线性 `sample_power_series` 批量写入 `scratch.energy`，
   相关循环中只剩 `pwr += on[lag-1] - off[lag-1]`，无逐样点 `std::norm`。
3. **共享模板缓存**：`prepare_sfd_filter` 在 `sparse_tmpl` 有效时调用
   `ensure_shaped_sparse_template_cached()` 预热 Stage-1/2/3 共享缓存；
   **SFD 点积仍保持既有 sparse/dense 数值路径**（成形模板是另一条数值路径，
   替换会改变所有检测 metric，故不用于 SFD）。
4. 新增 `qa_uwb_sfd_refactor.cc::test_sfd_discrete_grid_warm_call_zero_allocation`：
   强制两次离散网格热调用，逐项比较 `DemodScratch` 全部相关缓冲 `capacity()` 不变。

### 3.4 S4：Pipeline 增量补旋 `ensure_derotated_range()`

- `stage_sfd` 的 10 参数重载接收 `ensure_derotated(lo,hi)`；
  `run_discrete_grid(k_lo,k_hi)` 入口只计算本 pass 实际读取的区间
  （`expected + k·period` ± `kSfdNarrowHalf + 4`），调用回调补旋。
- `uwb_demod_pipeline.cc`：
  - 新增 `ensure_derotated_range()`：span 已覆盖 → **0 旋转**；不同 CFO / 无效 span →
    整段旋转；否则只旋转 `[req_lo, cur.lo)` 与 `[cur.hi, req_hi)` 左右缺口，
    并把 `derotated_span.range` 更新为并集。
  - `search_sfd_with_wide_rescue()` 删除原 `prepare_grid` 宽窗全量重旋
    （`[preamble_start, expected + 36P + sfd_len]`，8.84 m 约 10.9 万～30 万样点），
    改由回调按需补旋。
- **块对齐**：`rotate_window_range()` 将范围向外对齐到旋转内核的 1024 样点绝对块边界。
  块/递推两种内核都从范围首样点重算相位，对齐后每个样点的结果只取决于绝对下标，
  因此“增量缺口补旋”与“整段一次旋转”逐样点一致（新增单测实测最大误差 0）。
  每次旋转最多多算 1024 样点，诊断计数字段按实际对齐长度统计。

### 3.5 S5：清理失效重试死代码

- `anchor_and_verify_final_sfd()` 原 `if (!final_sfd_ok && rx_seed_refine_tail)` 重试块
  以 `seed_radius = 0` 重跑 `run_tail_retrack_and_cfo_refit()` + `run_final_sfd()`。
  但该函数的 `seed_radius` 已被 `(void)seed_radius;` 忽略，重跑在同一 raw 帧、
  同一 CFO、同一 derotated 数据上得到完全相同的结果，永远无法改变 `final_sfd_ok`。
- 已删除该块；`Qm35825Profile::rx_seed_refine_tail` 与 `DemodResult::stage_tail_retrack_fallbacks`
  字段保留（后者现在恒为 0），API / 日志字段兼容。

## 7. 未覆盖项与风险

1. **未上板**：本报告全部为离线文件回放；`-14 dB` SFD-only 进锁不等于完整帧 FCS 能力。
2. **`native-avx512` 仅编译**：本机无 AVX-512 运行环境；未做 AVX-512 实机功能/性能回归。
3. **S3 成形模板**：按方案书“保持 `sparse_tmpl` 优先级”的约束，`ensure_shaped_sparse_template_cached()`
   仅预热共享缓存，SFD 点积未切换到成形模板（切换会改变所有检测 metric，无法在“不放宽 QA 容差”
   前提下验证）；若后续需要，应单独做数值等价性验收。
4. **S2 的收益依赖真实信道 metric**：合成 `-14 dB` 单测证明“低门限 + 中心窗”路径可命中；
   真实 8.84 m 的 `0.008..0.02` 分布来自实采，换夹具需重新确认。
5. **`try2` 宽松分母波动**：5 ms 回放节拍/锁状态机会使 completed 在 424–432 间波动；
   验收以绝对 FCS 为准。
6. **MATLAB 未验证**：本轮未做 MATLAB 逐样点交叉验证（`UWB_demodulation/`）。
7. **paced/多 worker P99**：未做长时间 paced/多 worker 负载的 P99 统计。
