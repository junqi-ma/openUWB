## 0. 结论摘要

1. **正确性/交付门禁**：见 §6。`native-avx2`、`no-uhd` 全量 `ctest` 均
   0 failed；`scalar-debug` 串行全量 0 failed（并行 `-j8` 曾有一次与 SIC 无关的

   §6 实测日志为准。
2. **性能目标（修复前，§4 ABBA）**：“100 kHz CFO 抑制比”和“多 tap 线性缩放”
   两项达标；Live Hit 506k 后半段、`core_total`、短窗 135k L2 后半段三项未达标。
3. **未达标的主因（修复前实测）**：稀疏脉冲 apply 路径在任意非零 CFO 下都有约

4. `PacketProcessor` 原地路径带来的收益是真实的：Live 原地比异地少一次非 ROI

## 0.1 追加修复：稀疏 CFO 初始化固定开销（2026-11-22）

> 本节是 §4 ABBA 测量之后追加的单点修复与轻量复测。§4 的表格保留为
> **修复前**证据（优化版仍含约 106 us 的固定 CFO 设置开销）；本节数据为
> **修复后**实测，二者共同构成 before/after 对照。

### 根因（已由 `nm -u` 与源码确认）

`lib/sic/uwb_discrete_cir_reconstruct.cc` 的稀疏 CFO 初始化块在无
`-ffast-math` 下触发了大量库函数调用：

- `std::complex<double>` 乘法（`cur *= step`、`taps_eff` 预旋、块相位递推）
  被 GCC 降级为 **`__muldc3`**（1024 次带 NaN/Inf 分支的跨函数调用）；
- 20+ 次 `std::exp(std::complex<double>)` 被降级为 **`cexp`**；
- 计时块内还调用了 `is_b3_simd_disabled()`（未强制时每次 `getenv`）。

### 修复内容（仅 `lib/sic/uwb_discrete_cir_reconstruct.cc`）

1. `build_rotation_table()`：1 次 `sin/cos` + 4 路独立 double 实/虚部递推
   生成 `rotation[0..1023]`，无 `std::complex` 乘法、无 `cexp`，无长串行依赖链。
2. `taps_eff`：只做 1 次 `sincos(omega*lag_lo)` 与 1 次 `sincos(omega)`，
   `d=1..tap_count-1` 用手写实/虚部递推；零 CFO 仍直接使用 `model.taps`
   （逐位不变）。
3. `CfoBlockState`：内部改为 double `base_r/base_i/step_r/step_i`，
   块递推与每 16 块 re-anchor 均手写；并将哨兵从 `-1` 改为
   `INT64_MIN`（验证中发现非稀疏路径首块可合法为 `-1`，旧哨兵会漏掉
   `exp(-jω·1024)` 整块相位；该 bug 已修复并有既有单测覆盖）。
4. `is_b3_simd_disabled()` 移出 `t_phase` 计时块。
5. 顺带清理同文件其余同类调用点：非稀疏旋转表/块递推、scale 的
   `conj(w)*ref` 与模板误差、`add_pulse_fragment` 的复数乘。

### 轻量验证（严格按本次要求，未重跑全量门禁/120 进程 ABBA）

- 构建：`env -u LD_LIBRARY_PATH cmake --build --preset dev-avx2 -j 20` 通过。
- 符号：`uwb_discrete_cir_reconstruct.cc.o` 对
  `__muldc3|__mulsc3|cexp` 的未定义引用为 **0**。
  归档中其余引用来自 `uwb_discrete_cir_estimator.cc`、
  `uwb_fullpacket_sic_core.cc`、`uwb_preamble_sic_core.cc`（基线同样存在，

## 2. 基准方法

### 2.1 序列与环境

- 单进程串行，`taskset -c 4` 固定单核；所有命令前 `env -u LD_LIBRARY_PATH`。
- 每个场景、每个二进制执行 **ABBA**：`A(基线) → B(优化) → B(优化) → A(基线)`，
  共 **5 轮**；即每个配置每个二进制 **10 个进程样本**。
- 每个进程先 **10 次 warmup**，再测 **30 次**；进程内与跨进程均记录原始样本。
- 统计口径：对全部 300 个逐次样本做 nearest-rank **p50/p95**；
  抑制比取逐次中位数（同一输入为常量）。
- 原始逐次样本：`/tmp/opencode/wave2-raw/*.raw.jsonl`（120 个进程文件）；
  每个进程的汇总 JSON：`/tmp/opencode/wave2-abba/*.json`。
- 未在测量窗口内运行其他构建。

### 2.2 计时项定义与注意事项

- `core_total`：`sic_process_unified` 内部 `steady_clock`；
  edge 场景该入口不填父计时，故使用调用方 `steady_clock`。
- `reconstruct_us` / `subtract_us` / `recon_zero/scale/conv/cfo`：
  来自库返回的 `SicUnifiedTimings` / `DiscreteCirResult`。
- `roi_energy_extra_us`：优化融合路径（`suppression_energy_valid == true`）为
  **0**；基线及未融合路径单独计时一次
  `compute_roi_energies(y, out, sub_lo, sub_hi, …)`。
- `back_half = reconstruct + subtract + roi_energy_extra`。
- **重要口径**：优化的 `ihat == nullptr` L1D 分块路径把“相减 + ROI 能量”融合进
  `reconstruct_us`，其 `subtract_us` 只剩 ROI 外的拷贝（原地时为 ~0.03 us）。
  因此跨二进制比较应看 `back_half`，不能只看 `reconstruct`/`subtract` 单项。
- apply-layer（`cfo`、`taps`）为兼容基线只能走非 `_ex` 的独立入口，该入口会对
  `n` 做一次逐样点有限性/幅值扫描（n=137664 时约 15 ms），故这些行的
  `core_total` **不能**当重构耗时；本报告只用其 `reconstruct_us` / 抑制比。
- 基线原地模式的 `suppression_db` 恒为 0 dB：相减后再回读 y/out 的已知陷阱；
  该行仅用于说明“基线原地不支持正确度量”，不作为质量对比。

### 2.3 随机性与夹具

- 全部夹具由固定 seed 的 `mod::make_random_psdu` /
  `mod::modulate_one` / `mod::modulate_pulse_list` 生成，无外部 `testdata/` 依赖。
- 噪声底为确定性 LCG 抖动 + 常量 floor；`cfo` 场景 floor 取 `1e-6` 以留出
  抑制比量化余量。
- 每次输出都检查全部 `n` 个样点 `isfinite`，非有限立即非零退出。

### 2.4 工具 CLI

```sh
bench_sic_reconstruct_opt --scenario live-hit|short-l1|short-l2|cfo|taps|edge \
  [--inplace] [--cfo-hz HZ] [--taps N] [--reps N] [--warmup N] \
  [--json] [--raw PATH]
```

- `live-hit` 默认同时跑 sparse/shaped-sparse × 异地/原地；`--inplace` 只跑原地。
- `--cfo-hz` 限制 `cfo` 场景的频偏；`--taps` 限制 `taps` 场景的 tap_count。
- `--json` 每个配置输出一行机器可读 JSON；`--raw` 追加逐次样本 JSONL。

| L2 | 优化 | 552.60 / 816.81 | 204.61 / 293.92 | 0.35 / 0.59 | 0 / 0 | **204.95 / 294.38** | 52.223 |

- L1：`core_total` -11.6%，但 `back_half` **+20.8%（回归）**；L1 优化路径的
  `recon_cfo_rot_us` 中位数 105.58 us，基线 2.88 us，是回归的直接原因。
- L2：`core_total` -2.0%，`back_half` -9.5%，**未达到 ≤100 us**。
- 两者抑制比与基线完全一致（L1 28.437 dB，L2 52.223 dB）。

### 4.3 高频偏抑制（apply-layer，20-tap，`lag_lo=-4`，多径模型 lags {-4,0,10,15}）

确定性多径 CIR：`h = {0.30, 0.10, 0.30, 0.90}`（对应 lag -4/0/10/15）。
接收信号严格按 `y[j] = exp(j·w·(j-q)) · Σ_l h[l]·x[j-q-l]` 生成
（`x` 为同一 unit-impulse 包），因此“事件起点相位近似”会在大 lag 上暴露误差。

| CFO | 路径 | 基线抑制 dB | 优化抑制 dB |
| ---: | :--- | ---: | ---: |
| 0 Hz | sparse-pulse | 104.970 | 104.970 |
| 0 Hz | non-sparse discrete | 104.970 | 104.970 |
| 20 kHz | sparse-pulse | 55.160 | 104.970 |
| 20 kHz | non-sparse discrete | 104.970 | 104.970 |
| 50 kHz | sparse-pulse | 47.201 | 104.970 |
| 50 kHz | non-sparse discrete | 104.970 | 104.970 |
| **100 kHz** | **sparse-pulse** | **41.181** | **104.970** |
| **100 kHz** | **non-sparse discrete** | **104.970** | **104.970** |

优化后的 sparse-pulse 与 non-sparse **逐值一致**（104.970 dB），
在 100 kHz 下由基线的 41.181 dB 提升 63.79 dB，满足“≥52 dB 且与 NonSparse
一致”。

### 4.4 多 tap 缩放（apply-layer，sparse-pulse，零 CFO，`ihat=nullptr`）

| tap_count | 基线 `reconstruct` p50/p95 | 优化 `reconstruct` p50/p95 | 基线比值/20 | 优化比值/20 |
| ---: | ---: | ---: | ---: | ---: |
| 16 | 62.93 / 90.46 | 196.04 / 249.58 | 1.036 | 0.919 |
| 20 | 60.71 / 74.85 | 213.36 / 310.49 | 1.000 | 1.000 |
| 24 | 70.09 / 102.99 | 228.26 / 315.51 | 1.154 | **1.070** |
| 32 | 76.56 / 100.26 | 231.55 / 304.60 | 1.261 | **1.085** |

- 优化 24/20、32/20 均 **≤1.6×**，达标。
- 基线在本夹具上也没有复现任务书所述的“24/32-tap 退化 3–5×”（实测
  1.154/1.261），说明该夹具的事件密度下 20-tap 专用核与通用标量回退差距不大；
  但仍能看出优化把 32-tap 比值从 1.261 压到 1.085。
- 优化的绝对 `reconstruct` 高于基线，是因为该行把“相减 + ROI 能量”融合进了
  `reconstruct`，而基线把这两项计在 `subtract`/`roi_extra`；跨二进制应看
  `back_half`，本表的用途只是**同一二进制内的 tap 缩放**。

### 4.5 边缘裁剪

| 用例 | 二进制 | `committed` | `reason` | span | 抑制 dB |
| :--- | :--- | :---: | :--- | ---: | ---: |
| 左缘 `q=2`（lo=-2），clip off | 基线 | false | `context_truncated` | 0 | 0 |
| 左缘，clip on | 基线 | false | `context_truncated` | 0 | 0 |
| 左缘，clip off | 优化 | false | `context_truncated` | 0 | 0 |
| 左缘，**clip on** | 优化 | **true** | `committed_preamble_sparse_pulse` | 73170 | **105.506** |
| 右缘 `hi=n+2000`，clip off | 基线 | false | `context_truncated` | 0 | 0 |
| 右缘，clip on | 基线 | false | `context_truncated` | 0 | 0 |
| 右缘，clip off | 优化 | false | `context_truncated` | 0 | 0 |
| 右缘，**clip on** | 优化 | **true** | `committed_preamble_sparse_pulse` | **71172** | **105.508** |

右缘用例的支撑 `support_hi = 73172`、窗口 `n = 71680`，正好 `hi = n + 2000`；
优化在 `allow_partial_window_clip=true` 下把相减裁剪到 `[0, n)` 并提交，
span 从 73172 变为 71172（裁掉 2000 样点）。基线即使配置该字段也仍报
`context_truncated`，因为基线实现不转发该开关。

说明：edge 用公共入口 `reconstruct_and_subtract_unified` 直接喂入构造好的
`SicUnifiedChannel`，以隔离“边缘裁剪”本身；若走完整 `sic_process_unified`，
右缘会因 SFD 尾部被窗口截断而先在 comm 检测阶段失败，无法单独验证裁剪开关。

## 7. 残余风险与未覆盖项

1. **AVX-512 未执行**：本机 `i7-12700` 无 AVX-512 flags，只做了
   `native-avx512` 全量编译与静态库强符号核验，未运行任何 AVX-512 二进制。
2. **非零 CFO 固定开销（已修复）**：§0.1 已将 1024 点相位表、逐 lag 预旋与
   块相位递推改为手写实/虚部 double 运算，`recon_cfo_rot_us` 由 105–107 us
   降至 **0.96–1.07 us**；零 CFO 仍走 `model.taps` 原路径（逐位不变）。
   `uwb_discrete_cir_reconstruct.cc.o` 对 `__muldc3|__mulsc3|cexp` 的引用为 0。
   归档中 `uwb_discrete_cir_estimator.cc`、`uwb_fullpacket_sic_core.cc`、
   `uwb_preamble_sic_core.cc` 仍有同类引用（基线同样存在，且不在
   `apply_discrete_cir_pulses` 路径）；若后续优化这些后端，可复用同一手写递推。
3. **独立 apply 入口的整窗有限性扫描**：`cfo`/`taps` 为兼容基线只能调用非
   `_ex` 入口，n=137664 时该扫描约 15 ms，故这些行的 `core_total` 不代表重构
   性能；报告已改用 `reconstruct_us` 与抑制比。该扫描在基线/优化两库中相同。
4. **优化 `ihat != nullptr` 诊断路径的逐样点有限性检查**：实测给 apply-layer
   `reconstruct` 增加约 250 us；live 路径使用 `ihat==nullptr` 的分块融合路径，
   不支付该检查。故 `cfo` 行的绝对 `reconstruct` 不能外推到 live。
5. **基线原地 0 dB**：基线在 `out == y` 时先写后读，抑制比恒 0；本报告没有
   把它当作优化前后质量对比，只作为“基线原地不可用”的证据。
6. **L1D 分块路径的口径**：`reconstruct` 已含融合相减/能量，`subtract` 仅剩
   非 ROI 拷贝；跨二进制比较必须使用 `back_half`。
7. **短窗 L1 回归（已修复）**：修复前优化 L1 后半段比基线慢 20.8%，与第 2 条
   同源；§0.1 后短窗 L1 后半段为 **62.65 us**（修复前 168.79 us，-62.9%）。
8. **无硬件/闭集证据**：全部为软件合成夹具；未做上板、未做 MATLAB 检测位置
   交叉验证，不能据此声明测距或真实空口性能。
9. **并发工作区**：测量期间其他协作者修改过测试文件（库源码未变）；本报告
   的库二进制对应 23:38 的 `dev-avx2` 静态库。

## 10. 最终总结

- **通过**：100 kHz/20-tap 抑制比（优化 104.970 dB，与 NonSparse 一致；
  基线 41.181 dB）；24/32-tap 相对 20-tap 缩放（1.070/1.085，≤1.6×）；
  `rx_sic` 29/29、`dsp_extra` 7/7、`native-avx2`/`no-uhd`/`scalar-debug` 全量
  ctest、install consumer。
- **未通过**：Live Hit 506k 后半段（原地 262.45 us，目标 ≤150 us）、
  Live Hit `core_total`（sparse 异地/原地 866.35/923.81 us，目标 ≤560 us）、
  短窗 135k L2 后半段（204.95 us，目标 ≤100 us）。
- **主要阻塞**：优化稀疏路径在任意非零 CFO 下有约 105–107 us 固定相位设置
  开销（基线同口径 2.88 us）；其次是异地模式仍需全窗非 ROI 拷贝。解决该固定
  开销后，Live 原地后半段约 156 us，已接近目标。
- **未覆盖**：本机无 AVX-512，未执行 AVX-512 二进制；无上板与 MATLAB 证据。
