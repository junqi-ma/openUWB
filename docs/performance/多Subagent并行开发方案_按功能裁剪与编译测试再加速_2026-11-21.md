## 2. 按功能单选裁剪架构设计（`UWB_DEV_SCOPE` + 域精确链接）

### 2.1 `UWB_DEV_SCOPE` 与细分开关映射（顶层 [CMakeLists.txt](../../CMakeLists.txt)）

新增统一总开关 `UWB_DEV_SCOPE`（`AUTO`/`all`/`rx`/`tx`/`twr`/`radar`，默认 `all`）与对应布尔开关（供高级用户微调，且 `UWB_DEV_SCOPE=all` 时全部为 `ON`）：

| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| **`all`**（默认，交付与 CI） | `ON` | `ON` | `ON` | `ON` | `ON` | `ON` | 全部库、App、测试与安装规则（行为与当前完全一致） |
| **`rx`** | `OFF`（仅留声明/按需） | `ON` | `ON` | `OFF` | `OFF` | `OFF` | `support` + `dsp` + `phy_hrp` + `sic` + `radio` + RX runtime；`openuwb_rx` / `uwb_dw3000_decode` / `openuwb_capture`；`rx_sic` + `dsp_extra` QA |
| **`tx`** | `ON` | `OFF` | `OFF` | `OFF` | `OFF` | `OFF` | `support` + `dsp` + `phy_hrp_tx`（仅 `uwb_hrp_mod_core.cc`）；`uwb_qa_uwb_hrp_mod_core.cc` + `uwb_benchmark_hrp_mod`（及预留 `openuwb_tx` 入口） |

> **关键边界保护**：
> 1. 当 `UWB_DEV_SCOPE != all` 时，配置阶段输出醒目提示并禁用 `install()` / `install_consumer`（避免残缺构建误安装或污染系统环境）；
> 2. 交付验收预设（`native-avx2`、`no-uhd`、`native-avx512`、`scalar-debug`、`dev-avx2`）均保持 `UWB_DEV_SCOPE=all`；新增 `dev-rx`、`dev-tx`、`dev-radar`、`dev-twr` 4 个日常开发预设，分别写入独立构建目录 `build/dev-{rx,tx,radar,twr}`，互不干扰。

### 2.2 需要配合切开的两处最小边界

取消 `uwb_register_qa()` 里硬编码的 `uwb_native uwb_twr_phy`，改为支持 `LINK_LIBS` 参数或按子目录/白名单自动分配最小库：

## 3. 多 Subagent 并行调度拓扑（Wave 1 → Wave 4）

为最大化并行度、同时避免合并冲突，拆分为 **Wave 1（底座）→ Wave 2（4 路零冲突并行）→ Wave 3（收敛与次级优化）→ Wave 4（全局验证）**。建议使用 `workspace: "branch"`（或独立 git worktree）执行各 Worker。

```text
Wave 1（CMake 构建底座 + PCH 修复 + 功能裁剪；可拆为 2 路先合入，也可由 1 名经验主力 1 轮落地）
  ├─ Subagent-CMAKE-CORE   : CMakeLists.txt + CMakePresets.json + lib/CMakeLists.txt + lib/*/CMakeLists.txt + apps/CMakeLists.txt
  └─ Subagent-TESTS-BASE   : tests/CMakeLists.txt（修复 PCH 宏/ISA 匹配 + 按域精确链接 + UWB_ENABLE_* 注册裁剪 + 轻量 lib/apps PCH）

         ▼ 合入并验证：PCH 0 -Winvalid-pch 警告 + dev-{rx,tx,twr,radar} 均可单独编通 + dev-avx2 全绿

Wave 2（最大并行度！4 路严格零文件重叠同时开工，全部基于 Wave 1 修复后的高速底座编译）
  ├─ Subagent-QA-PHY       : 拆分 tests/unit/phy/qa_uwb_demod_core.cc -> 4 个独立 shard + demod_core_test_helpers.h
  ├─ Subagent-QA-SIC-RADIO : 拆分 tests/unit/sic/qa_uwb_preamble_sic_core.cc -> 3 个独立 shard；隔离/修复 qa_uwb_fixed_tone_cancel_source.cc flake
  ├─ Subagent-TWR-DEC-A    : 下沉 twr_timestamp / twr_config_effective / twr_config_validator / twr_config_util / twr_frame 实现到 lib/twr/uwb_twr_config_frame.cc

         ▼ 4 路各自本地跑通对应域 CTest 后依次快合（Wave 2 唯一的汇合文件 tests/CMakeLists.txt 与 lib/twr/CMakeLists.txt 留给 Wave 3 收口）
```

   - 性能零退化：`benchmark_sc16_burst_core`、`benchmark_hrp_mod`、`bench_unified_timing` 串行对照；
   - 量化收益报表（记录进新验收报告）：对比本方案开头实测基线（680.3 s CPU / 65 links / 10.14 s `rx_sic` 墙钟 / 26.2 s TWR 单 TU）与改造后各维度耗时。

## 6. 宿主机环境一步到位建议（与 Wave 1 并行准备）

本方案在软件侧就能拿回绝大部分收益；如宿主机具备安装权限，执行一次以下命令可让第 2 项加速再叠一层乘法器：

```sh
sudo apt-get update && sudo apt-get install -y ccache lld
```

安装后重新 configure（`CMakeLists.txt` 已自动探测 `ccache`），所有 `dev-*` 构建目录及各 Subagent 的分支 worktree 将共享编译缓存与极速链接器。
